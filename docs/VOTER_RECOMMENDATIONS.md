# JSON-рекомендации для модуля «Избиратель»

Приложение включает два опубликованных набора для выборов в Государственную Думу 2026 года: «Умное голосование» и «Новый парламент». Их наличие не означает одобрения источника или содержания. По умолчанию УмГ имеет приоритет, а «Новый парламент» дополняет отсутствующие округа и типы бюллетеней. Совпадением считается одинаковый тип бюллетеня в том же округе или УИК. В свёрнутых настройках объединения можно назначить другой приоритетный набор или показать все варианты параллельно. Пользователь также может искать только по выбранным источникам и переносить отдельные варианты в личный план. Дополнительный набор добавляется только после выбора локального JSON-файла или подтверждённой загрузки по HTTPS-ссылке.

Рабочий пример находится в [`voter-recommendations-example.json`](voter-recommendations-example.json).

Встроенные машиночитаемые наборы и проверяемые исходные данные находятся в
[`data/recommendations`](../data/recommendations/README.md). Список «Нового
парламента» сформирован из 225 карточек страницы
`https://elections.newparliament.ru/candidates.html` стандартным парсером
`scripts/parse_new_parliament_candidates.py`.

## Формат версии 1

Корневой объект:

- `schemaVersion` — обязательное число `1`;
- `title` — обязательное название набора;
- `publisher` — необязательное имя политического актора или организации;
- `election`, `publishedAt`, `sourceUrl` — необязательные сведения о наборе; `sourceUrl`, если указан, должен начинаться с `https://`;
- `contentSha256` — необязательный SHA-256 канонического JSON-массива `recommendations`;
- `recommendations` — непустой массив, не более 5000 элементов.

Поля рекомендации:

- `region`, `city`, `district`, `districtNumber`, `precinct` — территория;
  `districtNumber` хранит номер округа, а отсутствие поля или `"*"` означает,
  что ограничение не задано;
- при поиске `precinct` сравнивается целиком после удаления префикса «УИК» и
  знака `№`: запрос `27` не совпадает со значением `127`;
- `ballotType` — обязательный тип бюллетеня;
- `choice` — обязательный текст выбора: кандидат, партия, список или иной вариант;
- `party`, `candidateNumber`, `note` — необязательные пояснения;
  `candidateNumber` — номер кандидата в бюллетене, а не номер округа.

Стандартные значения `ballotType`:

- `federal_party_list` — федеральный партийный список;
- `federal_single_mandate` — федеральный одномандатный округ;
- `regional_party_list` — региональный партийный список;
- `regional_single_mandate` — региональный одномандатный округ;
- `municipal` — муниципальный бюллетень;
- `other` — другой бюллетень.

Неизвестный тип тоже будет показан, поэтому формат можно расширять без обновления приложения.

## Проверка целостности

Предпочтительный вариант — опубликовать рядом с JSON отдельную SHA-256 всего файла и передать пользователю хэш по другому доверенному каналу. Пользователь вставляет его в поле при импорте; при несовпадении набор не сохраняется.

Дополнительно можно указать `contentSha256`. Это хэш UTF-8 представления массива `recommendations`, сериализованного в компактный JSON с порядком полей из схемы приложения. Он защищает только массив рекомендаций, а не метаданные. Из-за требований к канонической сериализации отдельный хэш всего файла проще и надёжнее для издателя.

## Ограничения безопасности и приватности

- Загрузка по сети выполняется только по явному нажатию пользователя, только через HTTPS, без cookies и учётных данных, с лимитом 2 МБ.
- В браузере удалённый сервер должен разрешать CORS. Если не разрешает, пользователь может сам скачать JSON и импортировать файл.
- Приложение проверяет структуру и хэш, но не подтверждает личность издателя и не оценивает политическое содержание.
- Наборы и личный план хранятся локально: в приватных настройках Android-приложения или `localStorage` сайта. Это не шифрование от человека, получившего доступ к разблокированному устройству или профилю браузера.
- Приложение не отправляет списки, фильтры, личный план или другие пользовательские данные.
