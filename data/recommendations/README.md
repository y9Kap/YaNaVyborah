# Списки рекомендаций

## Госдума 2026 — Умное голосование

- `gosduma-2026-umg.source.json` сохраняет структуру исходного PDF: регион,
  номер и название одномандатного округа, кандидата и партию. Общая рекомендация
  по федеральному партийному списку вынесена в `partyListRecommendation`.
- `gosduma-2026-umg.yanavyborah.json` можно импортировать в раздел
  «Избиратель» приложения. Он содержит общую рекомендацию по федеральному списку
  и 214 записей по одномандатным округам.

JSON сформирован из `GOSDUMA-2026-UMG.pdf`. Сам исходный PDF не добавлен в
репозиторий. Контрольная сумма исходника записана в `sourcePdfSha256` первого
файла, поэтому происхождение данных можно проверить без публикации PDF.

Для повторной генерации нужен Python 3.11+ и `pdfplumber`:

```bash
python3 -m pip install -r scripts/requirements-gosduma-2026.txt
python3 scripts/parse_gosduma_2026_pdf.py /path/to/GOSDUMA-2026-UMG.pdf
```

Парсер проверяет число строк, уникальность номеров округов, обязательные поля и
известные названия партий. Он извлекает слова по координатам колонок, потому что
обычное копирование текста из подписанного PDF искажает несколько строк.

## Госдума 2026 — Новый парламент

- `new-parliament-gosduma-2026.source.json` сохраняет 225 карточек исходной
  страницы: регион, номер и название округа, кандидата и партию, а также URL и
  SHA-256 загруженного HTML.
- `new-parliament-gosduma-2026.yanavyborah.json` — готовый встроенный набор для
  приложения. Он содержит рекомендации по всем одномандатным округам 1–225.

Для повторной загрузки и генерации дополнительных зависимостей не требуется:

```bash
python3 scripts/parse_new_parliament_candidates.py
```

Для воспроизводимой проверки ранее скачанного HTML передайте путь к нему первым
аргументом. Парсер принимает только полный набор округов 1–225 без повторов,
проверяет обязательные поля и известные названия партий.
